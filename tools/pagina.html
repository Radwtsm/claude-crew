Usi l'app Claude? · 1 · Le regole comuni

  1. Premi Copia le regole qui sotto.
  2. Su claude.ai o nell'app Claude: Impostazioni → Generali (o Profilo) → campo delle preferenze personali.
  3. Incolla sotto le tue preferenze. Quando le regole cambiano, sostituisci solo il pezzo tra le due righe regole crew: quello che hai scritto tu resta tuo e vince sempre.

Usi l'app Claude? · 2 · Le skill

Una skill insegna a Claude un tipo di lavoro. Si caricano da computer (claude.ai o app desktop) e poi valgono anche sul telefono.

  1. Premi Scarica sulla skill che vuoi: arriva un file .zip, non aprirlo.
  2. Impostazioni → Funzionalità (Capabilities): accendi Esecuzione di codice e creazione di file se è spenta.
  3. Nella sezione Skill premi Carica skill e scegli lo zip.
    {{SKILLS}}

Quando una skill cambia, la vedi aggiornata qui: riscaricala e ricaricala.

Hai una skill o una regola da condividere?

Di' al tuo Claude "condividi questa skill con la crew" (serve la skill condividi-skill): la ripulisce da dati personali e ti prepara uno zip da mandare in chat a chi gestisce la crew. Hai solo un'idea? Proponila qui (account GitHub gratuito) o scrivila in chat.

Il tuo modo di usare Claude (come ti chiama, il tono, i tuoi metodi) resta nelle tue preferenze: la crew non lo tocca.
