# Frasi brevi (crew)

Bastano queste parole: Claude apre da solo la skill giusta. Ogni progetto può avere le sue (es. agenzia: README →
Frasi brevi). Una frase nuova utile a tutti → aggiungila qui.

| Scrivi | Cosa fa |
|---|---|
| «organizza il mio Claude» | struttura di regole, skill, memoria; contesto snello (`organizza-claude`) |
| «configura il mio Claude» | repo personale, memoria unica, barra di stato (`configura-claude`) |
| «misura i token» | byte caricati a ogni sessione (`personale.py misura`) |
| «aggiorna la crew» | plugin nuovi e aggiornamenti (`installa-crew`) |
| «annota» | il problema appena risolto diventa una lezione (`annota-lezione`) |
| «condividi con la crew» | una tua skill alla libreria (`condividi-skill`) |
| «raccogli le mie skill» | inventario di tutti i tuoi strumenti (`raccogli-skill`) |
| «trappole?» | prima di script, hook, ssh, test: le insidie già note (`trappole-tecniche`) |
| «sì» / «no» / «1» | risposta a una domanda a crocette: basta l'opzione |
