# Plugin di Pleyades: quale serve per cosa

Se il tema serve al lavoro e le skill del plugin non sono tra le tue: proponi in una riga di riaccenderlo
(`claude plugin enable <nome>@claude-crew`, se manca `claude plugin install <nome>@claude-crew`; vale con
`/reload-plugins`). Una volta per tema; se non serve davvero, taci. Gestione completa: skill `installa-crew`.

- `codice`: scrivere codice, script, hook, ssh, Docker, test, git.
- `design-app`: schermate, menu, flussi di app e siti; linee guida Apple.
- `grafica`: loghi, miniature, post social, banner, icone, texture e skin Minecraft.
- `video-ffmpeg`: tagliare, comprimere, convertire video, sottotitoli, formati social.
- `motion-design-codice`: animazioni e reel generati in codice (Node, canvas, ffmpeg).
- `after-effects-pannelli`: pannelli CEP e script ExtendScript per After Effects.
- `blender-riga-di-comando`: scene e render Blender da script Python.
- `indesign-script`: impaginati InDesign da script (magazine, libro, PDF).
- `server-minecraft`: server Minecraft Java, plugin e mod, lag, crash, backup.
- `shopify-tema`: tema Shopify con la Shopify CLI.
- `tema-studio`: colori dello studio per Claude Code.
- `progetto-crew`: solo progetti fatti insieme su più settori (`progetto.md`).
